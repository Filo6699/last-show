LAST SHOW - ВСЕ ЗВУКИ ПЕРВОЙ ГЛАВЫ
========================================

Все звуки сделаны с нуля (синтез кодом). Старые временные файлы игры не использовались.
Чужих записей нет. Голоса персонажей (папка 9) созданы нейросетью синтеза речи Kokoro
(лицензия Apache 2.0, коммерческое использование разрешено) на выдуманном «цирковом языке»
и обработаны отдельно для каждого персонажа.

MP3_слушать/      - понятные русские названия, чтобы прослушать и выбрать.
WAV_для_игры/     - те же звуки в исходном качестве (48 кГц, 24 бит) с английскими именами для кода.
                    Номер и папка совпадают с MP3: «MP3_слушать/2_.../05_...mp3» = строка 05 в списке ниже.
Список_звуков.csv - таблица (открывается в Excel): MP3 ↔ WAV ↔ где используется.
Только_прослушать_-_разделы_1-2_подряд.mp3 - склейка для прослушивания, В ИГРУ НЕ ДОБАВЛЯТЬ.

«цикл» - файл повторяется по кругу без шва. «моно» - для размещения в 3D, без эха; «с эхом» - готовая версия.
Перед подключением: в scripts/main.gd поставить AUDIO_ENABLED = true.
