# The Last Show

First-person horror visual novel made with Godot 4.7.2 and GDScript.

Import `project.godot` in Godot, wait for asset import, then press **F5** and select **Новая игра**. Keep the **Compatibility** renderer.

Controls: **WASD** to move, **mouse** to look, **E** to interact, **Space/Enter** to advance dialogue, **Esc** to pause.

[Download build](https://github.com/Filo6699/last-show/releases)
